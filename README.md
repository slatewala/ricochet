# Ricochet

Aim a neon laser. Bounce off walls. Hit the red target before your bounce budget runs out.

## Play

- Drag = aim
- Tap = fire
- Beam reflects off walls, costs one bounce per hit
- Score = levels cleared

## Build

```
flutter pub get
flutter run
flutter build apk --release
```
